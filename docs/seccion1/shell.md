***Shell***

Bash Shell es un intérprete de comandos y lenguaje de scripting utilizado principalmente en sistemas Linux y Unix 
que permite a los usuarios interactuar con el sistema operativo mediante instrucciones de texto, facilitando la ejecución de comandos, 
la administración de archivos y directorios, la automatización de tareas y la creación de scripts para realizar procesos 
de forma rápida y eficiente desde la línea de comandos.
