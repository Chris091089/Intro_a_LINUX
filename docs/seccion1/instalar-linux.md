**Instalación de Debian**

***Si el sistema operativo en windows 11:***<br>
Desde el buscador de Windows escribir `cmd` <br>
En la terminal escribir y ejecutar el comado `wsl -d Debian` <br>
*Nota: Esta acción activará el susbsistema operativo de linux para Windows e instalará el intérprete de línea de comandos.*
<br>
<br>
***Otras versiones de windows:***<br>
Desde el buscador de Windows escribir `cmd`<br>
En la terminal escribir y ejecutar el comando `wsl --install`<br>
*Acciones ejecutadas:*<br>
Activación del subsitema de Linux para Windows<br>
Activa la Plataforma de Máquina Virtual<br>
Instala el kernel de WSL<br>
REINICIAR EL EQUIPO<br>
<br>
En la terminal escribir y ejecutar el comando `wsl --list --online`<br>
*Mostrará el listado de distribuciones disponibles*<br>
En la terminal escribir el comando `wsl --install -d Debian`<br>
REINICIAR EL EQUIPO<br>
ABRIR EL ICONO DE DEBIAN E INGRESAR USUARIO Y CONTRASEÑA<br>
