**Distribuciones de LINUX**

**Debian:**<br>
1.- Software libre<br>
2.- Estable y seguro<br>
3.- Soporte de hardware extenso<br>
4.- Ofrece un instalador flexible<br>
5.- Proporciona actualizaciones de versiones<br>
6.- Base para otras distribuciones<br>
7.- Es una comunidad<br>
[Documentación de debian](https://www.debian.org/intro/why_debian)<br>

**Ubuntu:**<br>
1.- Fácil de usar<br>
2.- Gratuito<br>
3.- Seguro<br>
4.- Alta personalización<br>
5.- Posee variantes<br>
6.- Comunidad solidaria<br>
7.- Bajos requisitos del sistema<br>
[Documentación de ubuntu](https://fossbytes.com/reasons-to-use-ubuntu-linux-advantage/)<br>

**RedHat:**<br>
1.- Acceso a un panel personalizado<br>
2.- Acceso para registrarse en Red Hat Summit<br>
3.- Versiones de prueba extendidas de los productos y acceso gratuito a los programas para desarrolladores<br>
4.- Capacitaciones de primer nivel para partners<br>
5.- Aumento de tus conocimientos<br>
6.- Acceso completo a los productos<br>
[Documentación de RedHat](https://www.redhat.com/es/blog/maximizing-your-experience-top-6-benefits-having-red-hat-account)<br>
