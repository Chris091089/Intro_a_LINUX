** diferencia entre mayúsculas y minúsculas**

En Bash, el uso de mayúsculas y minúsculas es significativo porque el sistema distingue entre ambos tipos de caracteres.<br>
<br> 
Esto significa que nombres de archivos, directorios, variables y comandos escritos con diferentes combinaciones de letras 
mayúsculas y minúsculas se consideran elementos distintos. Por ejemplo, `archivo.txt` y `Archivo.txt` son archivos diferentes, 
al igual que las variables `nombre` y `NOMBRE`. Por convención, las variables de entorno suelen escribirse en mayúsculas (como `PATH` o `HOME`), 
mientras que las variables definidas por el usuario generalmente se escriben en minúsculas para facilitar su identificación y evitar conflictos.
