
**Construcción de una orden**

***El intérprete de comandos*** espera que le indiquemos una línea de órdenes para ejecutar la tarea que le hayamos indicado<br>
La sintaxis básica de una orden es `COMANDO [OPCIONES] [ARGUMENTOS]`<br>
<br>
Con el comando le **indico qué tiene que hacer**, en las opciones cómo debe hacerlo y con los argumentos le indico los elementos donde tendrá que realizar la acción<br>
Para diferenciar entre las partes de una linea de órdenes se utilizan los espacios<br>
<br>
<br>
`ls -la REPORTE`
