**Comodines**

La ventaja del uso de comodines en `Linux` es que permiten manipular 
varios archivos o directorios al mismo tiempo mediante patrones de búsqueda, 
lo que ahorra tiempo, reduce errores y facilita la automatización de tareas.<br>
<br> 
Por ejemplo, en lugar de especificar cada archivo individualmente, 
se pueden usar expresiones como `*.txt` para seleccionar todos los archivos de texto o archivo?`.txt` 
para trabajar con archivos que siguen un patrón determinado, haciendo más eficiente la administración del sistema y el uso de comandos.
